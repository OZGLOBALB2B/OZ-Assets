חיבור למאגר GitHub

כדי לשמור שינויים והחלפת קבצים ישירות לאתר. הפרטים נשמרים מקומית בדפדפן הזה בלבד.

איך יוצרים טוקן? (הסבר קצר)
1. ב‑GitHub: Settings → Developer settings → Personal access tokens → Fine‑grained tokens → Generate new token
2. תחת Repository access בוחרים את המאגר של האתר.
3. תחת Permissions → Repository permissions → Contents בוחרים Read and write.
4. מייצרים, מעתיקים את הטוקן ומדביקים כאן. הטוקן נשמר רק בדפדפן שלכם.
אין לכם טוקן / מעדיפים ידני? אפשר בכל שלב ללחוץ על "הורדת content.json" בלשונית "מתקדם", ולהעלות את הקובץ + הקבצים החדשים למאגר ידנית.
